// why NeoNano

Familiar on day one.

No modes to learn before you can type. The power is there when you reach for it.

Aa

nano-style writing

Type straight away. Undo, redo, mark and select, cut, copy, paste, find, and go to line, all on Ctrl and Alt keys.

:

vi-style palette

F1 opens a : prompt. Save, open, find, go to a line, switch themes, count words, or reopen the config with cfg.

{ }

configure everything

Line numbers on the left or right, relative numbers, themes, per-color overrides, and every keybind, in one TOML file.

so

plugins are shared objects

Build a plugin from the template, drop the .so in ~/.nnanoplugins, and enable it by name in your config.

$

one-line install

One script installs NeoNano from its GitHub release, checks every download against GitHub's sha256, and updates it later. It can also install the NeoNanoQOL plugins.

C

small and native

Written in C with ncurses. No interpreter and no runtime to install.

// install

Install in one line.

The script needs no source code. It reads the latest NeoNano release, checks the download against GitHub's sha256, and installs it. Then it asks whether you want the NeoNanoQOL plugins.

Install (asks about NeoNanoQOL) curl -fsSL https://raw.githubusercontent.com/RenCupDotDev/NeoNano/main/install.sh | bash
Install with the NeoNanoQOL plugins curl -fsSL https://raw.githubusercontent.com/RenCupDotDev/NeoNano/main/install.sh | bash -s -- --qol
Install system-wide (needs sudo) curl -fsSL https://raw.githubusercontent.com/RenCupDotDev/NeoNano/main/install.sh | sudo bash -s -- --system
Update (applies updates without asking) curl -fsSL https://raw.githubusercontent.com/RenCupDotDev/NeoNano/main/install.sh | bash -s -- --update
Preview, change nothing curl -fsSL https://raw.githubusercontent.com/RenCupDotDev/NeoNano/main/install.sh | bash -s -- --dry-run --qol
Start it nnano notes.txt
Uninstall (keeps your config) curl -fsSL https://raw.githubusercontent.com/RenCupDotDev/NeoNano/main/install.sh | bash -s -- --uninstall
Uninstall and delete your config curl -fsSL https://raw.githubusercontent.com/RenCupDotDev/NeoNano/main/install.sh | bash -s -- --purge

Needs Linux on x86_64, with curl, jq, sha256sum and libncursesw. Run the install command again to check for updates. Your config is kept.

// config

One TOML file for everything.

Created on first run in ~/.config/neonano/. Open it with Alt+I or cfg, then apply with Alt+K or reload.

# config.toml
theme = "neonano"

[editor]
tab_width = 4
use_spaces = true
undo_levels = 500

[view]
line_numbers = "right"
relative_numbers = true

[colors]
text = "#ffffff"

[keys]
save = ["ctrl+s", "f2"]

[plugins]
enabled = ["hello"]
# from the F1 palette, live
goto 42
theme mytheme
reload

# ~/.config/neonano/themes/mytheme.toml
[colors]
background = "#1e1e2e"
text = "#cdd6f4"
// plugins

A plugin is a shared object.

Build a .so from the NeoNano-Plugin-Template repository, copy it to ~/.nnanoplugins/, add its name to [plugins] enabled, and restart. The NeoNanoQOL repository has ready-made plugins for a directory tree, a terminal pane, a welcome page, a word counter and language servers.

#include "plugin.h"

static const PluginAPI *api;

static void cmd_hello(Editor *e, const char *arg) {
    char msg[200];
    snprintf(msg, sizeof msg, "Hello %s! This file has %zu lines.",
             (arg && *arg) ? arg : "there", api->line_count(e));
    api->message(e, msg);
}

void neonano_plugin_init(const PluginAPI *a) {
    if (a->version < 5) return;
    api = a;
    a->add_command("hello", "hello [name]  greet and show the line count", cmd_hello);
    a->bind_key("f10", "hello");
}
