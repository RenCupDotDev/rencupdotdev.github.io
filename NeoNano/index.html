// why NeoNano

Familiar on day one.

No modes to learn before you can type. The power is there when you reach for it.

Aa

nano-style writing

Type straight away. Undo, redo, mark and select, cut, copy, paste, find, and go to line, all on Ctrl and Alt keys.

:

vi-style palette

F1 opens a : prompt. Save, open, find, run shell commands, or change any setting live with :set.

{ }

configure everything

Line numbers on the left, right, or off. Themes, per-color overrides, every keybind, autosave, and the header format.

py

plugins are folders

A folder with an app.py and a setup(api) function. Turn it on by name in your config.

$

one-line install

One installer that lets you pick pipx, uv, or native, with update and uninstall built in.

0

no dependencies

Only the Python standard library and curses. Python 3.11 or newer.

// install

Install in one line.

The installer asks how you want to install: pipx, uv, or native. Pick one and it does the rest.

Linux, choose a method curl -fsSL https://rencupdotdev.github.io/install/neonano.sh | bash
Linux, pipx directly (recommended) curl -fsSL https://rencupdotdev.github.io/install/neonano.sh | bash -s -- --pipx
Linux, uv directly curl -fsSL https://rencupdotdev.github.io/install/neonano.sh | bash -s -- --uv
Linux, native directly (no pip) curl -fsSL https://rencupdotdev.github.io/install/neonano.sh | bash -s -- --native
Start it nnano notes.md
Windows, Python 3.11+, from the repo folder pip install windows-curses && pip install .
Uninstall (keeps your config) curl -fsSL https://rencupdotdev.github.io/install/neonano.sh | bash -s -- --uninstall
Uninstall and delete your config curl -fsSL https://rencupdotdev.github.io/install/neonano.sh | bash -s -- --purge

Run the install command again to update to the latest release. Your config is kept.

// config

One TOML file for everything.

Created on first run. Open it with Alt+I or :config, then apply with Alt+K or :reload.

# config.toml
theme = "neonano"

[editor]
tab_width = 4
autosave_seconds = 30

[view]
line_numbers = "right"
relative_numbers = true

[colors]
text = "#ffffff"

[keys]
save = ["ctrl+s", "f2"]
# from the : palette, live
:set view.line_numbers none
:set editor.tab_width 2
:theme mono
:execute git status

# themes/mytheme.toml
name = "mytheme"
[colors]
background = "#1e1e2e"
text = "#cdd6f4"
// plugins

A plugin is a folder.

Put an app.py in plugins/your-name/, add the name to [plugins] enabled, and restart.

def setup(api):
    # a palette command:  :hello world
    @api.command("hello")
    def cmd_hello(ed, arg):
        ed.message(f"hello {arg or 'world'}")

    # an action a keybind can call:  [keys] say_hello = "alt+g"
    @api.action("say_hello")
    def act_hello(ed):
        ed.message("hello from a keybind")

    # an event hook
    api.on("save", lambda ed, path: ed.message(f"saved {path}"))
